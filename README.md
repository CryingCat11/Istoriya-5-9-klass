# Тетради по истории, 5–9 классы

Интерактивные тетради к вводным занятиям. Сайт: https://cryingcat11.github.io/Istoriya-5-9-klass/

## Кабинет учителя: «Маркер» для тетрадей

Тетради на сайте работают сами по себе и хранят ответы в браузере ученика. Чтобы видеть ответы у себя, запусти кабинет из каталога `marker/`: учитель выдаёт ученику тетрадь по личной ссылке, ответы сохраняются на сервере, а в кабинете видно, что ученик пишет прямо сейчас.

[Как запустить](marker/README.md)
