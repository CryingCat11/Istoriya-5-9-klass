# «Маркер» для тетрадей по истории

Кабинет учителя для тетрадей 5–9 классов. Учитель добавляет ученика, выдаёт ему тетрадь и отправляет ссылку. Ученик открывает тетрадь по ссылке, ответы сохраняются на сервере сами, их можно продолжить с другого устройства. В кабинете видно состояние каждой тетради («Ещё не открыта», «Пишет сейчас», «В работе», «Сдана») и все ответы. Страница с ответами обновляется каждые 5 секунд, так что на занятии видно, что ученик пишет. Сданную тетрадь можно вернуть в работу.

На главной странице кабинета (`/`) открыта демоверсия: те же главная и тетради, что на сайте. Их может открыть кто угодно, ответы там остаются только в браузере и на сервер не уходят. На сервер попадают только ответы в тетрадях, выданных по ссылке, и хранятся отдельно от демоверсии.

Тетради берутся из корня репозитория (`5-klass.html` … `9-klass.html`) и читаются заново при каждом открытии, так что правки в тетрадях видны без перезапуска. Внизу тетради появляется полоска с именем ученика, состоянием сохранения и кнопкой «Сдать тетрадь». Сброс тетради кодом учителя тоже стирает ответы на сервере.

## Попробовать локально

Нужен Node.js 22.13 или новее, сторонних пакетов нет. Из корня репозитория:

```bash
cd marker
npm run demo
```

Открой адрес, который напечатает сервер, и введи показанный код учителя. В демо есть два ученика и одна выданная тетрадь. Ссылку ученика открой в приватном окне, чтобы пройти путь с обеих сторон. У каждого запуска демо своя временная база.

## Запуск на сервере

```bash
node -e 'console.log(require("node:crypto").randomBytes(24).toString("base64url"))'
MARKER_TUTOR_CODE='<сгенерированный код>' MARKER_URL='https://<адрес кабинета>/' npm start
```

- `MARKER_TUTOR_CODE` — код входа в кабинет, от 24 символов.
- `MARKER_URL` — внешний адрес, если кабинет работает за HTTPS-прокси: по нему строятся ссылки, а куки передаются только по HTTPS.
- `MARKER_DB` — путь к базе SQLite, по умолчанию `marker/data/notebooks.sqlite`.
- `MARKER_HOST` и `PORT` — где слушать, по умолчанию `127.0.0.1:4318` (тренажёр ОГЭ по обществознанию занимает 4317, их можно запускать рядом).
- `MARKER_TZ` — часовой пояс для времени в кабинете, по умолчанию `Europe/Moscow`.

Личные ссылки дают доступ к тетрадям ученика, поэтому отправляй их лично и не пиши полные пути `/s/…` в журналы прокси. Если ссылку переслали, открой страницу ученика и нажми «Заменить личную ссылку»: старые ссылки и входы перестанут работать, ответы сохранятся.

Резервная копия: `sqlite3 /path/to/notebooks.sqlite ".backup '/path/to/backup.sqlite'"`.

## Проверка

`npm test` поднимает сервер с временной базой и проходит весь путь: вход учителя, выдача тетради, вход ученика по ссылке, сохранение, защита от перезаписи с другого устройства, сдача и сохранность после перезапуска.

## Установка на сервер одной командой

`deploy/setup.sh` ставит на чистый Ubuntu или Debian оба кабинета (тетради по истории и тренажёр ОГЭ по обществознанию), Caddy с HTTPS, обновление из GitHub каждые 5 минут и ежедневные резервные копии баз. Запусти от root:

```bash
curl -fsSL https://raw.githubusercontent.com/CryingCat11/Istoriya-5-9-klass/main/marker/deploy/setup.sh | bash
```

Новые версии из GitHub сервер подтягивает сам каждые 5 минут. По умолчанию тетради открываются на `misharepet.study`, тренажёр — на `oge.misharepet.study`. Другие адреса задаются через `HIST_HOST` и `OGE_HOST`. Повторный запуск обновляет код и не трогает коды входа и базы.
